Recursive Sequences

Consider the sequence $\{a_n\}$ recursively defined by $$a_1=1, \qquad a_{n+1}=\frac{3+a_n}{2} \qquad (n\geq 1).$$ Such sequences are called recursive sequences, where each term is defined in terms of the previous term. We will explore whether such sequences converge and, if so, how to determine their limits.

First, let us calculate the first 10 terms of $a_1=1,\; a_{n+1}=\dfrac{3+a_n}{2}$.

Bounded Sequences

Before we describe how to determine whether a recursive sequence converges, we first introduce some terminology.

  • We say that $\alpha$ is an upper bound of $\{a_n\}$ if $a_n\leq\alpha$ for all $n\in\mathbb{N}$. In this case, $\{a_n\}$ is bounded above.
  • We say that $\beta$ is a lower bound of $\{a_n\}$ if $a_n\geq\beta$ for all $n\in\mathbb{N}$. In this case, $\{a_n\}$ is bounded below.
  • We call $\{a_n\}$ bounded if it is both bounded above and bounded below.

Based on our calculations above, this sequence is bounded below by $1$ and bounded above by $3$. It is also bounded below by $0$ and above by $5$, or bounded below by $-1$ and above by $100$. Clearly, bounds are not unique.

Least upper bound. $\alpha$ is called the least upper bound of $\{a_n\}$ if:

  • $\alpha$ is an upper bound, and
  • if $\alpha'$ is another upper bound, then $\alpha'\geq\alpha$.

Greatest lower bound. $\beta$ is called the greatest lower bound of $\{a_n\}$ if:

  • $\beta$ is a lower bound, and
  • if $\beta'$ is another lower bound, then $\beta'\leq\beta$.

The code below calculates the same first 10 terms more efficiently using a for loop.

Python
a = 1  # a1
print("The value of a1 is", a)

for n in range(2, 11):  # from a2 to a10
    a = (3 + a) / 2
    print("The value of a" + str(n) + " is", a)

The value of a10 is 2.99609375

Based on these calculations, the greatest lower bound of $\{a_n\}$ is $1$ and the least upper bound of $\{a_n\}$ is $3$.

Monotonic Sequences

An important class of sequences is the class of monotonic sequences. We say that $\{a_n\}$ is:

  • increasing if $a_n\leq a_{n+1}$ for all $n\in\mathbb{N}$;
  • strictly increasing if $a_n<a_{n+1}$ for all $n\in\mathbb{N}$;
  • decreasing if $a_n\geq a_{n+1}$ for all $n\in\mathbb{N}$;
  • strictly decreasing if $a_n>a_{n+1}$ for all $n\in\mathbb{N}$.

A sequence is monotonic (or monotone) if it is either increasing or decreasing.

Consider

$$a_1=1, \qquad a_{n+1}=a_n+\frac{(-1)^n}{n} \qquad (n\geq 1).$$
Python
a1 = 1  # initial term
print("The value of a1 is", a1)

a = a1  # use a as the current term

for n in range(2, 11):
    a = a + ((-1)**n) / n
    print("The value of a" + str(n) + " is", a)

A Recursive Sequence That Appears to Converge

Now consider

$$a_1=2, \qquad a_{n+1}=\sqrt{7+a_n} \qquad (n\geq 1).$$

Let us calculate the first 20 terms.

Python
import math

a = 2  # a1
print(f"a1 = {a}")

for n in range(2, 21):  # a2 to a20
    a = math.sqrt(7 + a)
    print(f"a{n} = {a}")

Based on these calculations, $\{a_n\}$ is increasing. We also observe that its terms stabilize near $3.19$. We call the value approached by the sequence its limit. The graph below provides a visual picture of this behavior.

Python used to create the graph
import math
import matplotlib.pyplot as plt

# Initialize first term
a = 2
terms = [a]

# Generate next 19 terms (up to a20)
for _ in range(19):
    a = math.sqrt(7 + a)
    terms.append(a)

# Prepare n values
n_values = list(range(1, 21))

# Plot the sequence
plt.figure(figsize=(8, 5))
plt.plot(n_values, terms, marker='o', linestyle='-',
         color='blue', label=r'$a_n$')
plt.title(r'Recursive Sequence: $a_1 = 2$, $a_{n+1} = \sqrt{7 + a_n}$')
plt.xlabel(r'$n$')
plt.ylabel(r'$a_n$')
plt.grid(True)
plt.legend()
plt.tight_layout()
plt.show()

The following theorem allows us to determine when monotonic sequences converge and is an important tool for studying recursive sequences.

Monotonic Convergence Theorem (MCT)

Let $\{a_n\}$ be an increasing sequence.

  • If $\{a_n\}$ is bounded above, then $\{a_n\}$ converges to $L=\mathrm{lub}(\{a_n\})$.
  • If $\{a_n\}$ is not bounded above, then $\{a_n\}$ diverges to $\infty$.

Similarly, let $\{b_n\}$ be a decreasing sequence.

  • If $\{b_n\}$ is bounded below, then $\{b_n\}$ converges to $L=\mathrm{glb}(\{b_n\})$.
  • If $\{b_n\}$ is not bounded below, then $\{b_n\}$ diverges to $-\infty$.

Recall: The recursive sequence $a_1=2,\; a_{n+1}=\sqrt{7+a_n}$ was increasing and bounded above, and it was converging. This illustrates the MCT.
