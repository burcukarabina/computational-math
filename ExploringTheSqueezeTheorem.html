Exploring the Squeeze Theorem

In the Numerical Exploration of Limits: Functions activity, we explored limits by looking at values of a function near a point.

In this activity, we will study a very useful tool for limits called the Squeeze Theorem.

The main idea is:

If a function is trapped between two other functions, and the two outside functions approach the same value, then the middle function must approach that same value too.

We will use tables and graphs to build intuition before stating the theorem formally.

Two functions that approach the same value

Let's start with two simple functions:

$$ g(x)=-x^2+1 $$

and

$$ h(x)=x^2+1. $$

Both functions approach $1$ as $x\to 0$. In other words, $$ \lim_{x \to 0} (-x^2+1) = \lim_{x \to 0} (x^2+1) = 1. $$

Let's check this numerically.

Python
x_values = [-0.15, -0.015, -0.0015, -0.00015,
            0.00015, 0.0015, 0.015, 0.15]

for x in x_values:
    g = -x**2 + 1
    h = x**2 + 1
    print(f"x = {x:.6f}   -x^2+1 = {g:.6f}   x^2+1 = {h:.6f}")

Find a function trapped between them

Now consider the function

$$ f(x)=x^2\sin\left(\frac{1}{x}\right)+1. $$

This function oscillates because of the $\sin(1/x)$ part.

However, it is multiplied by $x^2$, which becomes very small near $0$. But then we add $1$ to it, so it should get close to $1$.

Let's compute some values.

Python
import math

Comparing all three functions

We will now compare:

$$ g(x)=-x^2+1, $$

$$ f(x)=x^2\sin\left(\frac{1}{x}\right)+1, $$

and

$$ h(x)=x^2+1. $$

The goal is to see whether the middle function stays between the other two functions.

Python
import math
import matplotlib.pyplot as plt

x_values = []

# Use negative x-values first
x = -1
while x < -0.01:
    x_values.append(x)
    x = x + 0.001

# Use positive x-values next
x = 0.01
while x <= 1:
    x_values.append(x)
    x = x + 0.001

upper_values = []
middle_values = []
lower_values = []

for x in x_values:
    upper_values.append(x**2 + 1)
    middle_values.append(x**2 * math.sin(1/x) + 1)
    lower_values.append(-x**2 + 1)

plt.plot(x_values, upper_values, label="h(x) = x^2+1")
plt.plot(x_values, middle_values, label="f(x) = x^2 sin(1/x)+1")
plt.plot(x_values, lower_values, label="g(x) = -x^2+1")

plt.axvline(x=0, linestyle="--")
plt.axhline(y=0, linestyle="--")

plt.xlabel("x")
plt.ylabel("y")
plt.title("A function squeezed between two functions")
plt.grid(True)
plt.legend()
plt.show()

As you can see from the graph above, the oscillating curve appears to stay between $y=-x^2+1$ and $y=x^2+1$.

A table showing the squeeze

Now we will make a table showing all three functions:

$$ -x^2+1,\qquad x^2\sin(1/x)+1,\qquad x^2+1. $$

We want to check whether

$$ -x^2+1 \leq x^2\sin(1/x)+1 \leq x^2+1. $$

Python
import math

x_values = [0.5, 0.2, 0.1, 0.05, 0.01, 0.005, 0.001]

print("x        -x^2+1        x^2 sin(1/x)+1       x^2+1")

for x in x_values:
    lower = -x**2 + 1
    middle = x**2 * math.sin(1/x) + 1
    upper = x**2 + 1

    print(f"{x:.6f}     {lower:.6f}     {middle:.6f}     {upper:.6f}")

Does the inequality hold in general?

We know that for every real number $t$, the values of $\sin(t)$ oscillate between $-1$ and $1$, so we can write

$$ -1\leq \sin(t)\leq 1. $$

So for $t=1/x$, when $x\neq 0$, we have

$$ -1\leq \sin(1/x)\leq 1. $$

If we multiply all parts by $x^2$, we get

$$ -x^2 \leq x^2\sin(1/x) \leq x^2. $$

Adding $1$ gives

$$ -x^2+1 \leq x^2\sin(1/x)+1 \leq x^2+1. $$

This means

$$ g(x)\leq f(x)\leq h(x), $$

where

$$ g(x)=-x^2+1,\qquad f(x)=x^2\sin(1/x)+1,\qquad h(x)=x^2+1. $$

The open interval condition!

A very important detail:

For the Squeeze Theorem, we need

$$ g(x)\leq f(x)\leq h(x) $$

to hold on an open interval around $a$, possibly excluding $a$ itself.

In this example, $a=0$.

The function

$$ x^2\sin(1/x)+1 $$

is not defined at $x=0$, but that is okay.

Limits are about what happens near the point, not necessarily at the point.

So we care that

$$ -x^2+1 \leq x^2\sin(1/x)+1 \leq x^2+1 $$

holds for $x\neq 0$ in an open interval around $0$.

The Squeeze Theorem

Here is the formal idea.

Suppose there is an open interval containing $a$ such that

$$ g(x)\leq f(x)\leq h(x) $$

for all $x\neq a$ in that interval.

If

$$ \lim_{x\to a}g(x)=L $$

and

$$ \lim_{x\to a}h(x)=L, $$

then

$$ \lim_{x\to a}f(x)=L. $$

In our example,

$$ \lim_{x\to 0}(-x^2+1)=1 $$

and

$$ \lim_{x\to 0}(x^2+1)=1. $$

Since

$$ -x^2+1 \leq x^2\sin(1/x)+1 \leq x^2+1, $$

we conclude that

$$ \lim_{x\to 0} \left( x^2\sin(1/x)+1 \right) = 1. $$
